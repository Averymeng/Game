## 三、技术硬约束（不可更改）

- 技术栈：TypeScript + Vite + Three.js + DeepSeek API + localStorage
- **画风：蛋仔派对风**（Q 版圆润、明亮糖果色、卡通渲染 toon shading、**非像素风**）
- **不要用色调映射**（ACESFilmic 等会压暗降饱和），保持颜色明亮鲜艳
- 立体感靠「**强方向光 + 弱环境光**」制造明暗对比，不是靠后期处理
- API key 绝不可写进前端代码，必须走**后端代理**（Vite dev proxy / Vercel Serverless Function）
- DeepSeek 兼容 OpenAI 格式：`base_url=https://api.deepseek.com`、`model="deepseek-chat"`；**DeepSeek 没有 embedding 接口**，RAG 另选中文 embedding，MVP 先用关键词检索

## 四、产品需求浓缩

**世界观**：一个漂浮的「AI 世界」，5 座主题岛屿环绕中心广场，玩家空降中心广场逐岛闯关，通关全部 5 岛 = 成为 AI 达人。

**5 岛**（递进：认识→理解→使用→进阶→责任）：

| 岛 | 学什么 | MVP |
|---|---|---|
| 认识之岛 | AI 是什么 + AI 产品认知 | ✅ |
| 理解之岛 | 大模型原理、Token、幻觉、温度、memory、RAG | ✅ |
| 使用之岛 | 提示词工程、AI 实操、vibecoding | ✅ |
| 进阶之岛 | Agent、工具调用、MCP | 后续 |
| 责任之岛 | 成本、提示注入、边界 | 后续 |

**核心玩法循环**：探索地图 → 进入关卡（问答/任务）→ 卡壳求助卡卡（耗次数）→ 通关得知识点+星星 → 解锁下一关/岛 → 星星换求助次数/装扮 → 亲密度上升。

**5 种关卡类型**：问答·单选、问答·情境判断、任务·提示词拼装、任务·真实调 AI、任务·Vibe Coding。

**MVP 10 关**（认识岛3关 + 理解岛3关 + 使用岛4关）：
- 认识岛：①哪些是 AI 做的 ②生成式 AI 边界 ③认识 AI 产品
- 理解岛：④为什么 AI 胡说八道（幻觉）⑤让 AI 更老实还是更大胆（温度）⑥AI 的计费积木（Token）
- 使用岛：⑦提示词缺了什么 ⑧拼出正确的提示词 ⑨亲手写广告语（真调AI）⑩我的第一个 AI 作品（vibecoding）

**陪伴助手「卡卡」**：刀子嘴豆腐心的老师。毒舌吐槽但真心为你好，所有毒舌最终指向「我想让你真的学会」。有口癖（绑定情绪）、亲密度四档（初识→熟悉→亲密→家人）、求助分级（提示→思路→答案，有次数限制）。

**难度原则**：小白友好 ≠ 简单到不用动脑。用生活化场景 + 大白话出题；**术语后置**（通关后用小贴士揭示术语）。

**AI 架构**：能规则就规则（选择题判定、拼装判定、亲密度、解锁、存档全用规则），该 LLM 才 LLM（卡卡闲聊、求助、真调AI任务、vibecoding、开放问答评判、知识问答共 6 处）。兜底：「宁可不答也不错答」+「AI 失败降级到规则」。
