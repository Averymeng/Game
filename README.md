# 《卡卡的 AI 冒险》（暂定名）

一个让 AI 新手小白**边玩边学 AI** 的 3D 闯关游戏，内置毒舌但可靠的陪伴助手「卡卡」。

## 项目定位

- 世界观：一个由 6 座主题岛屿组成的「AI 世界」
- 玩法：闯关（问答 + 实操任务），从「完全不懂」成长为「AI 达人」
- 陪伴：卡卡陪你聊天、卡壳时分级求助（有次数限制）
- 画风：蛋仔派对风（Q 版圆润、非像素风）

## 技术栈

- Vite + TypeScript
- Three.js（3D low-poly + 卡通渲染）
- DeepSeek（LLM，聊天/求助/实操任务）
- 部署：GitHub Pages / Vercel
